# Tela-painel-estudos-bootstrap-tailwind

Projeto de página responsiva para a atividade Bootstrap e Tailwind CSS.

## Como executar no GitHub Codespaces

1. Abra **Code > Codespaces > Create codespace on main**.
2. Instale a extensão Live Server e reinicie a IDE online.
3. Aperte com o botão direito um dos dois arquivos `index.html` e aperte na opção `Open with Live Server`.
4. Após abrir uma nova guia no navegador, aperte na pasta do projeto, depois aperte na pasta que os projetos estão dentro e escolha entre bootstrap ou tailwind para abrir a tela que deseja.

## Requisitos demonstrados nas duas versões

1. Navbar: título, três links e menu mobile.
2. Carrossel: três slides, setas, indicadores e transição (Bootstrap nativa; Tailwind com troca de slides e classes de transição).
3. Cards: três áreas de estudo em grid responsivo.
4. Tabela: cinco atividades, cabeçalho, listras alternadas e rolagem horizontal em telas pequenas.
5. Formulário: nome, e-mail, área e objetivo, com validação HTML5. O envio é **simulado**, sem armazenamento.
6. Modal: título, descrição, fundo semitransparente e botões para fechar.
